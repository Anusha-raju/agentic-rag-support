# Printer Troubleshooting

## Symptoms
- Printer offline
- Jobs stuck in queue
- Wrong driver

## Steps
1. Power cycle printer and user device.
2. Clear print queue and restart spooler service.
3. Verify correct printer selected/default.
4. Reinstall driver from approved source.
5. Test print.

## Escalation
- Office printer outage → Facilities/IT ops
