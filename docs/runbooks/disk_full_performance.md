# Laptop Slow / Disk Full

## Symptoms
- Slow boot
- Apps freezing
- Low disk warnings

## Steps
1. Check disk space and top consumers.
2. Clear temp files and recycle bin.
3. Uninstall unused apps.
4. Move large files to cloud storage.
5. Check for malware scan (if policy allows).

## Escalation
- Hardware diagnostics if disk shows errors / SMART warnings
