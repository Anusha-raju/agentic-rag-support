# Software Installation Request

## Policy
Only approved software can be installed. Admin rights may be restricted.

## Steps
1. Collect software name/version, business justification.
2. Check approved catalog.
3. If approved: install via managed portal (Intune/Jamf/etc).
4. If not approved: submit security review ticket.

## Escalation
- Security review required for unapproved binaries or browser extensions.
