# Wi-Fi Cannot Connect

## Symptoms
- “Cannot connect to this network”
- Repeated password prompts
- Connected but no internet

## Steps
1. Forget network and re-add (correct SSID).
2. Restart network adapter.
3. Check captive portal (open browser).
4. Renew IP (Windows: ipconfig /release, /renew).
5. Verify DHCP availability.

## Escalation
- If office-wide → Network team (possible AP outage)
