# Email Not Syncing (Outlook/Gmail)

## Symptoms
- Inbox not updating
- Stuck in “Trying to connect”
- New emails on phone but not desktop

## Resolution Steps
1. Check service status (internal status page if available).
2. Verify internet connectivity.
3. Restart email client.
4. Re-authenticate (sign out/in).
5. Remove and re-add account profile.
6. Clear cache (Outlook OST rebuild) if allowed.

## Escalation
- Multiple users → possible service incident
- Single user with auth errors → Identity team
