# VPN Setup (Client Installation)

## Goal
Install and configure corporate VPN (e.g., Cisco AnyConnect / GlobalProtect).

## Steps
1. Confirm OS version and admin permissions.
2. Download approved client from internal software portal.
3. Install client and reboot.
4. Add VPN gateway URL (company standard).
5. Login using SSO + MFA.
6. Verify connection and route to internal resources.

## Validation
- Ping internal DNS
- Access intranet URL
- Confirm correct VPN profile selected
