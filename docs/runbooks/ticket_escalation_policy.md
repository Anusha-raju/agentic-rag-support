# Ticket Escalation Policy

## Severity
- P1: widespread outage / security incident
- P2: key workflow blocked for multiple users
- P3: single user blocked / workaround exists
- P4: minor issue / request

## Escalation Rules
- If resolution steps fail twice → escalate
- If issue impacts multiple users → escalate immediately
- If security suspicion (phishing/MFA fatigue) → escalate to Security

## Required Info for Escalation
- error message screenshot/text
- timestamps
- device OS/version
- network (home/office/VPN)
- affected systems
