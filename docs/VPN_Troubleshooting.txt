# VPN Troubleshooting Guide & Internal Tools Access

## Common Issues

### 1. VPN Connects but Internal Tools are Inaccessible
**Symptoms:**
- GlobalProtect/Cisco AnyConnect shows "Connected".
- Browser shows "Site can't be reached" or "DNS_PROBE_FINISHED_NXDOMAIN" for internal URLs (e.g., `https://jira.internal`).

**Root Causes:**
- DNS settings not updating incorrectly.
- Split tunneling misconfiguration.
- Expired Kerberos ticket.

**Resolution Steps:**
1. **Flush DNS Cache**:
   - Open Command Prompt as Administrator.
   - Run: `ipconfig /flushdns`.
2. **Check DNS Servers**:
   - Run `ipconfig /all`.
   - Ensure DNS servers are pointing to internal IPs (e.g., 10.x.x.x), not 8.8.8.8.
3. **Re-authenticate**:
   - Disconnect VPN.
   - Run `kinit` or use your SSO portal to refresh credentials.
   - Reconnect VPN.
4. **Browser Proxy**:
   - Ensure "Use automatic configuration script" is checked in Proxy settings if required strictly.

### 2. VPN Fails to Connect
**Symptoms:**
- Error: "Gateway not reachable".
- Authentication loop.

**Resolution Steps:**
1. Check internet connection.
2. Verify MFA token (push notification might be delayed).
3. Reinstall VPN client from the self-service portal.
